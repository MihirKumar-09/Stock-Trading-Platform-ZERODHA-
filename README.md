# Zerodha Clone (Basic Trading Platform) 📈
A basic clone of the Zerodha trading platform built for learning full-stack development.
This project simulates a simple stock trading environment where users can register, authenticate, and buy/sell stocks.

⚠️ Note: This is a learning project. Stock data is not fetched from real market APIs and is instead stored and managed in a database.

# Features 
User Authentication & Authorization

• Buy Stocks

• Sell Stocks

• Portfolio management

• Store and manage stock data in database

• Basic dashboard for viewing holdings

• Secure user login system

# How It Works 💪🏻
- User registers or logs in.

  Authentication token is generated.

- User can view available stocks.

- User can:
  • Buy stocks
  • Sell stocks

- Transactions are stored in MongoDB.

- Portfolio updates dynamically based on user actions.
